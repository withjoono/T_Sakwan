## 0. v1에서 무엇이 달라졌나

v1은 김태훈 교사의 분석 PDF(11p) 한 부만 보고 짠 기획이었다. 지금은 **5개 기관의 공식 모집요강 원문 249페이지**를 전부 읽었다. 그 결과 기획의 전제가 세 군데에서 바뀌었다.

| | v1 | v2 |
|---|---|---|
| 데이터 출처 | 3자 분석 PDF (재인용 리스크) | **공식 요강 원문** (1차 소스) |
| 경찰대 | "데이터 없음, 별도 정리 예정"으로 제외 | **48p 요강 전량 확보 → 독립 페이지로 편입** |
| 구조 | 사관 4개교 기준 하위 6 | 사관 4개교 + 경찰대 분리 + 2028 축, 하위 8 |
| 저작권 | 인용 허락 문의가 1순위 과제 | **해소** — 요강은 공공저작물, 3자 PDF 불필요 |

**가장 큰 소득은 저작권 문제가 사라진 것이다.** v1에서 1순위 과제로 잡았던 "원문 작성자에게 인용 허락 받기"는 이제 필요 없다. 모집요강은 각 학교가 공표한 공공 자료이고, 수치를 인용하는 데 허락이 필요하지 않다. 김태훈 선생님 자료는 앞으로 **해석의 참고**로만 쓰고, 사이트에 실리는 모든 숫자는 요강에서 직접 가져온다.

## 1. 교차검증 결과 — 3자 자료를 그대로 쓰면 안 되는 이유

요강 원문과 대조한 결과, 김태훈 PDF에서 **요강과 어긋나는 값 3건, 구조를 오해할 수 있는 표기 2건**이 나왔다. 선생님 자료의 품질이 낮아서가 아니라(대부분 정확했다), 이 종류의 데이터는 **3자를 거치면 반드시 어긋난다**는 증거다.

### 값이 다른 것

| 항목 | 김태훈 PDF | **요강 원문** | 영향 |
|---|---|---|---|
| **공사 체력검정 과락** (남 1,500m) | 8분 32초 이상 불합격 | **7분 32초 이상 불합격** | **1분 차이.** 이 값을 믿고 훈련하면 과락한다 |
| **해사 한국사 가산점** | 1급 5 / 2급 3 / 3급 2 | **1급 5 / 2급 4 / 3급 3** | 2·3급자 1점씩 손해 계산 |
| 육사 성적확인 마감시각 | 8/11 11:30 | **요강 내부 모순** (일정표 17:00, 본문 11:30) | 요강 자체 오류 — 육사에 직접 확인 필요 |

### 구조를 오해하게 되는 표기

- **해사 특별전형 8명** — PDF는 별도 행으로 표기해 "정원 외 8명"처럼 읽힌다. 요강은 **일반우선 85명 한도 안에 포함**되는 상한선이고, 합격자가 없으면 그냥 일반우선으로 흡수된다. 51 + 85 = 136 = 170의 80%로 정확히 맞아떨어진다.
- **공사 일반우선 40%→35% 축소** — 요강이 "2027 변경사항"으로 명시한 것은 **고교학교장추천 30%→35% 확대 하나뿐**이다. 일반우선이 줄어든 것은 그 결과이지, 별도로 고지된 변경이 아니다.

### 새로 확보한 것 (PDF에 아예 없던 데이터)

- 공사 **모집정원 235명** (남 199 / 여 36), 전형별 인원 검산 완료 (81+82+3+5+5+2+10+47 = 235)
- 공사 1차 합격 배수 — 남인문 4 / **남자연 6** / 여인문 8 / 여자연 10 (육사·해사의 남자연 5배수와 다름)
- 국간사 1차 배수 — **남 8배수 / 여 4배수** (4개교 중 유일하게 여자 배수가 남자보다 작다. 여자 정원이 76명으로 압도적이라 생긴 구조)
- 4개교 **체력검정 등급표 전량** (해사·국간사는 등급별 초 단위까지, 육사는 5종목 10.00~5.25점 배점표)
- 4개교 **내신 등급별 환산점수 전량**
- 경찰대 요강 **전부**

**이 표 자체가 콘텐츠다.** "3자 요약본과 공식 요강이 이만큼 다르다"는 것을 보여주는 것은, T사관이 요강을 직접 읽는 곳이라는 증명이 된다. `/admission` 허브에 "이 페이지의 모든 숫자는 각 학교 2027학년도 모집요강 원문에서 가져왔습니다" 한 줄과 함께 근거로 쓴다.

## 2. 요강을 읽고 발견한 것 — 콘텐츠 기둥 4개

기획을 뒤집을 만한 사실이 네 가지 나왔다. 페이지 구조는 이 네 가지를 중심으로 짠다.

### ① 2026년 8월 1일, 사관학교 4개교와 경찰대가 **같은 날** 1차 시험을 본다

5개 기관 요강이 모두 **2026. 8. 1.(토)**을 1차 시험일로 명시한다. 즉 **하나만 고를 수 있다.**

그런데 원서접수 시기가 다르다.

| | 원서접수 | 1차 시험 |
|---|---|---|
| 경찰대 (특별전형) | **2026. 5. 4. ~ 5. 14.** | 8. 1.(토) |
| 경찰대 (일반전형) | **2026. 5. 18. ~ 5. 28.** | 8. 1.(토) |
| 사관학교 4개교 | 2026. 6. 19. ~ 6. 29. | 8. 1.(토) |

**경찰대를 쓸지 말지는 5월에 이미 결정된다.** 사관학교 원서접수가 시작되기 3주 전이다. 이 사실을 6월에 아는 학생은 이미 선택지 하나를 잃은 상태다.

→ 이것이 이 페이지군 전체에서 **가장 가치 있는 단일 정보**다. 허브 최상단, `/schedule`, `/police` 세 곳에 배치한다.

### ② 같은 날 시험인데 **문제 구조가 완전히 다르다**

| | 사관학교 4개교 | 경찰대 |
|---|---|---|
| 국어 | 30문항 / 50분 | **45문항 / 60분** |
| 영어 | 30문항 / 50분 | **45문항 / 60분** |
| 수학 | 30문항 / 100분 | **25문항 / 80분** |
| 수학 범위 | 수학Ⅰ·Ⅱ + **선택과목 1** | **수학Ⅰ·Ⅱ만** (선택과목 없음) |
| 배점 | 국100·영100·수100 | 국100·영100·수100 (수학 3/4/5점, 주관식 5문항) |
| 합격 배수 | 계열·성별별 4~10배수 | **일괄 6배수** |

문항당 시간이 국어·영어 기준 사관학교 1분 40초, 경찰대 1분 20초다. **경찰대가 20% 더 빠듯하다.** 반대로 수학은 경찰대가 문항당 3분 12초로 사관학교(3분 20초)와 비슷하지만 선택과목이 없어 범위가 좁다.

→ "사관학교 준비하다가 경찰대도 같이" 가 안 되는 구조다. 이 비교표를 `/exam`의 중심에 놓고, 그대로 **모의고사 전환 동선**으로 쓴다.

### ③ 내신의 영향력이 학교마다 **3배 넘게** 차이 난다

1등급과 9등급의 총점 차이를 요강 환산표로 직접 계산했다.

| 학교 / 전형 | 내신 만점 | 1등급 | 9등급 | 격차 | **총점 대비** |
|---|---|---|---|---|---|
| 육사 (적성우수·종합) | 100 (교과90+출결10) | 90.0 | 83.0 | 7.0 | **0.7%** |
| 육사 (고교학교장추천) | 200 | 180.0 | 166.0 | 14.0 | **1.4%** |
| 해사 (전 전형) | 100 (교과90+출결10) | 90 | 75 | 15 | **1.5%** |
| 경찰대 | 150 (교과135+출석15) | 135 | 115 | 20 | **2.0%** |
| 국간사 (일반우선) | 125 | — | — | 약 27 | **약 4.3%** |

*(공사·국간사는 학추 배점이 두 배여서 격차도 두 배가 된다. 국간사는 교과 90점 만점 등급간 2.7점 균등 차이를 125점 만점으로 환산한 값.)*

**육사 적성우수는 1등급과 9등급의 차이가 1,000점 중 7점이다.** 공사 학추의 48점과 비교하면 7배 차이다.

→ "내신 3~4등급인데 사관학교 되나요?" 라는 상담 최다 질문에, **학교별로 다른 정답**을 줄 수 있다. `/method`의 핵심이자 상담 전환의 최대 지점.

### ④ 체력검정 과락선이 학교마다 최대 47초 차이

| 학교 | 종목 | 불합격 기준 |
|---|---|---|
| **공사** | 1,500m | **7분 32초 이상** ← 가장 엄격 |

공사와 해사 사이가 **47초**다. 그리고 육사는 아예 종목이 다르고(상대악력·교차윗몸일으키기·20m 왕복오래달리기·10m 왕복달리기·제자리멀리뛰기 5종목), 경찰대는 72kg 더미 끌기·27kg 기구 밀기·권총 방아쇠 당기기로 구성된 실무 시뮬레이션이다.

→ **목표 학교를 정하지 않고 체력을 준비하는 것은 의미가 없다.** 이것이 마이클래스(학교별 반 분리) 전환의 근거가 된다.

## 3. 2028 축 — 현재 확보 상태

폴더에 **2028 시행계획은 아직 없다.** 2027 모집요강 7개 파일만 있다. 다만 2027 요강 안에서 2028 정보를 하나 건졌다.

> **경찰대 2027 요강 표지 「2028학년도 입학전형 변경사항 알림」**
> 학생부 교과성적 산출방법을 **9등급제 → 5등급제**로 변경. 2028학년도부터 적용하며, 9등급제 이수자는 5등급제로 환산 처리.
> 2028 환산점수: 1등급 5점 / 2등급 4점 / 3등급 3점 / 4등급 2점 / 5등급 1점

사관학교 4개교 요강에는 2028 관련 언급이 **전혀 없다.** 따라서 지금 시점에 `/admission/2028`을 채울 수 있는 것은 경찰대 한 건뿐이다.

**설계 방침** — `/admission/2028`을 뼈대만 만들어 배포하고, 시행계획이 나오는 대로 채운다. 페이지를 나중에 만들지 않고 **지금 만드는** 이유는 두 가지다.

1. 검색엔진이 URL을 미리 알고 있어야 공고 직후 며칠 안에 색인된다. 공고 당일에 페이지를 새로 만들면 색인까지 2~3주가 걸리고, 그 기간이 검색량 피크다.
2. 현 고2가 이 사이트의 **핵심 고객**이다. 플래너와 모의고사는 1년 이상 준비하는 사람이 쓰는 도구지, 원서 쓰기 3개월 전에 오는 사람이 쓰는 도구가 아니다.

초기 콘텐츠는 "2028은 아직 미공개 / 확정된 것은 경찰대 5등급제 전환 하나 / 2027 기준으로 미리 준비할 것" 구성으로 충분하다.

## 4. 사이트맵

```
/admission                    입시 총정리 (허브)
├── /admission/schedule       일정·고사장 — 5개 기관 전 일정
├── /admission/exam           1차 필기 — 사관 vs 경찰대 문제 구조 비교
├── /admission/quota          모집인원·전형 구조·경쟁률
├── /admission/method         전형별 반영 비율 + 학생부(내신·출결) + 한국사
├── /admission/physical       신체검사 결격 기준 + 체력검정
├── /admission/changes        2027 변경사항
├── /admission/police         경찰대학 단독 정리
└── /admission/2028           2028 대비 (현 고2) — 시행계획 공고 시 확장
```

**경찰대를 왜 분리하나** — 4개 사관학교는 일정·과목·배점 구조가 거의 같아 한 표에 들어간다. 경찰대는 원서접수 시기(5월), 과목 구성(45/45/25문항), 수능 비중(50%), 연령 상한(42세 미만), 학과 배정(2학년 진학 시), 병역(장교 임관 아님, 병역법상 의무 이행) 전부가 다르다. 억지로 5열로 만들면 모든 표에 "해당 없음"이 절반씩 들어가 읽히지 않는다.

대신 각 하위 페이지 끝에 **"경찰대는 이 항목이 이렇게 다릅니다"** 3~4줄 비교 블록 + `/police` 링크를 고정 배치한다. 단, **`/schedule`과 `/exam`에서는 경찰대를 본문 표에 포함**한다 — 같은 날 시험이라는 사실과 문제 구조 비교가 그 페이지의 핵심이기 때문이다.

**`/essay`는 v1에서 철회한다.** 4개교 요강 모두 지원동기서를 "원서접수 시 제출"이라고만 쓰고 **문항·글자수를 명시하지 않는다.** 2027 양식이 공개되기 전에는 2026년 양식을 추정해 올리는 것밖에 안 되고, 그건 이 페이지군의 원칙에 어긋난다. 양식 공개 후 재검토.

```
├── exam.ts           시간표·범위·배점·산출식·배수
├── weights.ts        전형별 반영 배점
├── record.ts         내신 등급 환산표 + 출결
├── physical.ts       신체검사 결격 + 체력 등급표
├── changes.ts        2027 변경사항 + 2028 예고
└── police.ts         경찰대 (구조가 달라 분리)
```

**설계 원칙 3가지**

1. **슬러그를 `/class/[slug]`와 공유한다** — `army` · `navy` · `airforce` · `nursing` · `police`. 같은 상수를 `generateMetadata`와 본문 보강에서 가져다 쓰면, 요강이 바뀔 때 한 곳만 고쳐도 전 페이지가 따라온다.
2. **모든 값에 출처 필드를 붙인다** — `{ value, source: "육사 2027 모집요강 §6.3", note?: "요강 내부 불일치" }`. 화면에는 툴팁이나 각주로, 코드에서는 나중에 검증할 때 쓴다. 이번에 3자 자료에서 오차가 나온 경험이 있으니, **다음 갱신 때 무엇을 어디서 가져왔는지 남겨야 한다.**
3. **`⚠️불확실` 값은 타입으로 구분한다** — 요강 내부 모순(육사 성적확인 시각)이나 판독 불확실(육사 미래국방인재 수능 최저, 1차 점수 산출 공식 일부)은 `uncertain: true` 플래그를 달고, 화면에서 "학교 확인 필요"로 표기한다. **모르는 것을 아는 척하지 않는 것이 이 페이지군의 가장 큰 자산이다.**

## 8. SEO 설계

기존 `lib/seo.ts`의 `abs` / `breadcrumb` / `faqPage` / `graph` 헬퍼를 그대로 쓴다.

| 항목 | 처리 |
|---|---|
| title | 페이지별 고유, 60자 이내. 패턴 `"2027 사관학교 원서접수 일정·고사장 — T사관"` |
| description | 페이지별 고유 120~155자, **숫자를 넣는다** ("사관학교 원서접수 6.19~6.29, 경찰대는 5월. 1차 필기는 8.1(토) 동시…") |
| canonical | 전 페이지 `abs(path)` |
| JSON-LD | 전 페이지 `BreadcrumbList` + 허브에 `FAQPage` + 각 페이지 `Article`(datePublished / dateModified) |
| sitemap | `app/sitemap.ts` `ENTRIES`에 9개 추가. 허브 0.9 / 하위 0.8. changeFrequency — schedule·changes·2028 `weekly`, 나머지 `monthly` |
| 내부 링크 | 허브 ↔ 하위 양방향 + 하위 교차 + `/class/*`·`/mock`·`/1cha` 연결 |
| 본문 분량 | 페이지당 **2,000자 이상**. 표 안 숫자는 분량으로 안 쳐준다 — 설명 문단이 필요하다 |
| 갱신 신호 | `CONTENT_UPDATED`를 손으로 올린다. 빌드마다 오늘 날짜를 박으면 신뢰를 잃는다 |

**AI 검색 대응** — ChatGPT·Perplexity 크롤러는 JS를 실행하지 않는다. 이미 `output: 'export'`라 본문이 HTML에 들어가므로 유리한 조건이다. 여기에 더해:

- 표는 이미지가 아닌 **실제 `<table>`**로 (요강 인포그래픽을 그대로 쓰고 싶은 유혹을 이겨야 한다)
- 각 섹션 첫 문장을 **질문에 대한 직답**으로 쓴다. "2027학년도 사관학교 원서접수는 2026년 6월 19일 금요일 9시부터 6월 29일 월요일 17시까지입니다. 경찰대학은 이보다 한 달 이른 5월에 접수합니다." — AI가 인용하기 좋은 단문
- FAQ를 허브에만 두지 말고 하위 페이지마다 3~4개씩 배치
- **출처 명시** — "각 학교 2027학년도 모집요강 원문 기준, 최종 확인 YYYY-MM-DD". AI 검색은 출처가 명확한 페이지를 선호하고, 사람에게도 이게 신뢰의 근거다

## 9. 전환(홍보) 설계

| 페이지 | CTA | 이유 |
|---|---|---|
| 허브 | 모의고사 | 진입 직후엔 "내 위치"가 궁금하다 |
| schedule | Hub 가입 (D-Day 알림) | 일정을 본 사람은 놓칠까 봐 불안하다 |
| **exam** | **모의고사** | 가장 직접적. 시험 형식 설명 → 같은 형식으로 응시 |
| quota | 마이클래스 | 계열·성별 필터로 자기 조건을 입력한 직후 |
| **method** | **1:1 상담** | "내신 몇 등급이면?"은 학교별로 답이 갈려서 사람이 답해야 한다 |
| **physical** | **1:1 상담** | "나 이거 되나요"는 사람이 답해야 한다 |
| changes | 마이클래스 | 학추 확대 → "그럼 나는 뭘 해야 하나" |
| police | 1:1 상담 | 사관 vs 경찰대 선택은 개인차가 크다 |
| 2028 | Hub 가입 (공고 알림) | 지금은 줄 게 없고, 나중에 알려주는 게 유일한 가치 |

**CTA 원칙 3가지**

1. **한 페이지에 하나만.** 세 개를 다 붙이면 아무것도 안 눌린다.
2. **정보를 다 준 뒤에 놓는다.** 정보를 인질로 잡지 않는다 — 로그인 벽, 일부 가림 모두 금지. 크롤러에도 안 보이고, 신뢰도 잃는다.
3. **문장은 다음 행동으로.** "가입하기"가 아니라 "내 점수가 작년 합격선 어디쯤인지 확인하기".

상담 CTA는 기존 카톡 상담 채널과 연결한다. 폼으로 받을 경우 수집 항목은 **이름·연락처·목표 학교·학년**까지만. 성적·건강 정보는 폼에 넣지 않는다.
