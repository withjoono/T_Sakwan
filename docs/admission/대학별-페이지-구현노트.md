## 대학별 페이지 섹션 순서

한눈에 보기 → 전형 일정 → 1차 필기 → 모집인원·전형 구조 → 전형별 배점 →
학생부(내신)·한국사 → 체력검정 → 신체검사 → 면접 → 2027 변경사항(+⚠️ 확인 필요) →
2028 대비 → 고사장 → FAQ → CTA → 다음 단계 3링크 → 출처·면책

CTA는 페이지당 하나다. 육사·해사는 모의고사, 공사·국간사·경찰대는 1:1 상담.

## 데이터 원칙

1. 모든 숫자는 각 학교 2027 모집요강 원문에서 온다. 3자 요약 자료를 출처로 쓰지 않는다.
2. 요강에 없으면 "요강에 명시 없음"이라고 화면에 그대로 쓴다.
3. 요강 내부 모순·판독 불확실은 각 학교 데이터의 `uncertain` 배열에 남기고 페이지에 ⚠️로 노출한다.
   지우지 말 것. (예: 육사 성적확인 마감시각 17:00 vs 11:30)

경쟁률은 싣지 않았다. 요강에 없는 값이라 원칙 1에 어긋난다.
