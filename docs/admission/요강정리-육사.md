### 4.3 점수 산출 방식 (원문 수식, 레이아웃 손상으로 일부 ⚠️불확실)

1) 국어·영어 표준점수 산출 (수능과 동일 방식): `과목 표준점수 = (원점수-평균점수)/표준편차 × 20 + 100` ⚠️불확실 (원문의 분수식이 pdftotext 레이아웃 손상으로 기호가 흐트러져 정확한 연산 순서/상수 배치는 원본 PDF 대조 필요. "평균점수 100, 표준편차 20 (수능과 동일)"이라는 텍스트는 명확히 확인됨)
2) 수학 표준점수 산출: 공통과목 표준점수 + 선택과목(조정점수) 표준점수를 합산 (수능과 동일)
   - 공통과목 표준점수 배점비율: **74점**
   - 선택과목 표준점수 배점비율: **26점**
   - 선택과목 조정점수 산출식 포함 ⚠️불확실 (수식이 여러 줄에 걸쳐 겹쳐 추출되어 정확한 수식 구조 확인 불가. "수험생의 선택과목의 조정점수, 전체 응시자의 선택과목 조정점수 평균/표준편차"라는 변수명은 확인됨)
3) 1차 시험 필기 성적(반영 기본점수, **50점 만점**): `반영 기본점수 = (과목별 개인 취득 표준점수 / 과목별 최고 표준점수) × 50점` (⚠️불확실: 분수식이 손상되어 정확한 배열 확인 필요하나 서술은 원문에 명시)
   - 소수점 넷째 자리에서 반올림하여 셋째 자리까지 반영 (모든 전형과정 성적처리에 공통 적용)
   - **적성우수 우선선발 및 특별전형(재외국민자녀 전형 제외) 시 "반영 기본점수 × 6"으로 산출**
4) 동점자 처리: 반영 기본점수 동점 시 표준점수 총점이 높은 순으로 순위 산정, 표준점수 총점까지 동점이면 동일 순위.

### 4.4 1차 합격자 배수 (계열·성별)
- 남자: 인문계 **4배수**, 자연계 **5배수**
- 여자: 인문계 **8배수**, 자연계 **10배수**
- (단, **재외국민자녀 특별전형**은 남자 계열별 **8배수**, 여자 계열별 **12배수**)
- 위 배수는 일반전형·특별전형 공통 사항.
- 서류평가(미래국방인재) 별도 배수: 고등학교 추천 인원(학교별 3명) 중 성별·계열별 총점 순으로 남자는 계열별 모집정원의 **5배수**, 여자는 계열별 **8배수** 선발.

### 9.3 신체등위 (BMI 기준) — 재검/유예 규정
- 신체등위 3급: 2차 시험 최종심의위원회에서 합격 여부 결정
- 신체등위 4급: 유예기간 경과 이후 1~3급 충족 조건으로 심의하여 합·불 결정. 유예기간 경과 후 조건 미충족 시 최종선발 합격 불가

### 12.3 재외국민자녀 특별전형 (제13장)
- 개요: 외국에서 수학한 대한민국 국적자 중 수학능력·리더십 우수자 선발
- 지원자격: 육사 입학자격 + 외국에서 고등학교 1년 포함 연속 중·고교 과정 **3년(1,095일) 이상** 수학
  - 대상: 해외근무 공무원/상사직원 자녀, 외국정부·국제기구 근무자 자녀, 교포 자녀, 기타 재외국민(현지법인 근무자, 자영업자 등) 자녀
  - 동반체류: 해당 부+모 모두(한부모 가정은 해당 부 또는 모)
  - 실제 체류기간: 부모는 1년기준 2/3 이상, 학생 본인은 1년기준 3/4 이상 (1개 학년=365일 산정)
  - 체류국 고등학교 성적 평균 **B 이상**
- 1차 시험 합격기준: **남자 전체 모집정원의 8배수, 여자 12배수**
- 인원: 최종성적(600점 만점) 순 **5명 이내 선발** (합격자 없을 시 미선발)
- 미선발 인원 중 1차 시험에서 남 인문 4배수·자연 5배수 / 여 인문 8배수·자연 10배수 내 인원은 적성우수 우선선발 기회 부여, 이후 미선발 인원 중 2차 합격자는 수능 응시자에 한해 종합선발 기회 부여
- 내신: 미반영 (국내고 졸업자는 제7장, 외국계고 졸업자는 제7장 4. 비교내신 준용)
- 검정고시·홈스쿨링·사이버학습 등의 학력인정방법은 재외국민 지원 자격에서 **인정하지 않음**
- 동일 학년(학기) 중복 수료로 인한 수학기간은 인정하지 않음

## 13. 미래국방인재(미-국-인) 전형

- 정의: 고등학교 학교장 추천을 받은 자 중 **1차 필기시험 대신 학교생활기록부 서류평가**를 통해 우수인재를 선발하는 **우선선발** 전형
- 평가 방식: 서류평가(1,000점 만점) = 학업성취도(80%, 공통+일반+진로선택과목, 800점=400+240+160) + 학업태도(10%, 결석/지각/조퇴 감점, 100점) + 진로역량(10%, 권장 계열과목 관련, 100점)
  - 학업성취도: 공통·일반선택과목은 표준점수·등급점수 각 50% 반영 (등급점수: 1등급100~9등급5, §6 상세), 진로선택과목은 3단계 평가(A=100,B=75,C=50) 이수단위 가중평균
  - 학업태도: 기본점수 100점에서 결석(무단1일 -2점), 지각(무단1회 -1점), 조퇴(무단1회 -1점) 차감. 질병 사유는 미감점
  - 진로역량: 계열별 핵심과목(4과목, 5점/과목, 최대20점) + 권장과목(4과목, 4점/과목, 최대16점) 이수 수 + 핵심과목 성취도(40점)/권장과목 성취도(24점) — 성취도는 Z점수 기준 A~E 5단계 평가
- 고등학교 추천 인원(학교별 3명, 대행사이트 통해 추천) 중 성별·계열별 총점 순 남자 계열별 **5배수**, 여자 계열별 **8배수** 선발 (=1차 시험 합격자 선발)
- 수능 최저학력기준: ⚠️불확실 — 총괄배점표(§3)에 "(국,영,수, 탐구평균 中 3합 8)"이라는 문구가 확인되나, pdftotext 레이아웃 손상(다른 열과 겹쳐 추출됨)으로 정확한 산식(예: 국/영/수/탐구평균 중 3개 영역 등급 합이 8 이내 등)을 확정할 수 없음. §9장에는 "미래국방인재 전형 합격자가 수능 최저기준 미달 시 종합선발 대상자로 전환됨"이라고만 명시되어, 최저기준 존재는 확인되나 정확한 수치 산식은 원본 PDF 대조 필요.
- 중복지원 제한: 미래국방인재 지원 자격은 고등학교 학교장 추천을 받은 자에 한하며 **타 사관학교 중복지원 불가** (결격사유: "타 사관학교 중복 지원자(미래국방인재 전형에 한함)"은 불합격 사유)
- 우선선발 과락 기준(1차 필기 하위 20%)은 **미래국방인재 전형 지원자에게는 미적용**
- 특목고 관련 조항: **특성화고, 마이스터고, 영재학교, 예술고, 방송통신고, 학력인정고(각종학교 포함), 일반/종합고의 전문계반(학과), 외국고등학교 등 학생부 성적체계가 다른 학교는 지원불가**
- 지원서 접수 시 학교장 추천은 고교별 최대 7명(학교장추천전형 4명 + 미래국방인재전형 3명)까지 가능
- 2차 시험 조 선택: 마지막 2~3개 조에서 선택
- 배점(§9 우선선발 유형별 배점): 계 1,000점, 1차시험 합·불(서류평가 대체), 신체검사 합·불, 면접 800점, 체력검정 200점, 내신 미반영, 한국사가산점/체력가산점 미적용(- 표기)

- 합격자 발표 후 자격/신체검사 기준 미충족자: 가입학 등록 이후 건강검진·관찰·면담 등으로 불충족 확인 시 취소 가능, 서류 허위·위조·변조 확인 시, 질병·부상 등으로 화랑기초훈련 포함 생도교육 불가 판단 시, 정해진 기한 내 입학서약서 미제출 또는 포기서 제출 시, 고등교육법 제33조제1항 학력 미보유 시

## 16. 2027학년도에 새로 바뀐 것으로 문서에 명시된 부분
