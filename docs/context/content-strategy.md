# 콘텐츠 전략 — 페이지군의 범위 경계

## 3층 구조

| 층 | 경로 | 성격 | 출처 규칙 |
|---|---|---|---|
| 요강 사실 | `/admission` + 대학별 5 | 정확·완결 | **각 학교 모집요강 원문만.** 요강에 없으면 "요강에 명시 없음" |
| 설득 | `/promo/blog` | 전환용 글 | — |
| 검색 유입 (미구축) | 미정 | 요강 밖 질문 — 기출·경쟁률·합격선·신검 탈락·진로·자격 FAQ | **기사·기관 통계 등 출처를 본문에 명시** |

## 경계 규칙

- `/admission` 에는 **경쟁률·합격선·기출 같은 요강 밖 값을 넣지 않는다.** (데이터 원칙 1 — `docs/admission/대학별-페이지-구현노트.md`)
- 요강 밖 수요는 별도 정보 페이지군이 받는다. 출처를 명시하면 원칙과 충돌하지 않는다.
- 정보 페이지가 `/admission/*` 과 제목·본문이 겹치면 카니발라이제이션 → **요강 사실은 쓰지 말고 `/admission` 으로 링크**한다.
- `lib/sakwan/cutoffs.ts` 의 합격선은 예시 데이터다. 정보 페이지 근거로 쓰지 않는다.
- AI 검색 유입을 노리면 제목을 질문형으로 (`사관학교 문신 있으면 불합격인가요`).

## 주제 후보 (우선순위)

- **A (전환 직결)**: ① 1차시험 기출 분석(해설·경향, PDF 배포 경쟁 X) → 모의고사 ② 합격선·경쟁률 추이(출처 명시) → 모의고사 ③ 신체검사 불합격 기준 총정리 → 상담 ④ 체력검정 과락 기준 + 3개월 훈련 계획 → 플래너
- **B (진입 질의)**: 지원자격 FAQ / 사관 vs 경찰대 비교 / 졸업 후 진로·보수·의무복무 / 2028 변경사항 추적
- **C (로드맵)**: 중3·고1 로드맵 / 고2 겨울~고3 6월 역산 계획 / 사관·경찰형 생기부 설계

신체검사 콘텐츠는 건강 정보다 — 개별 건강 상태를 입력받는 자가진단 폼은 만들지 않는다(기획서 v2 §5-6).

## 시기 (검색 수요 달력)

- 9~11월: 2차시험·신체검사·면접 후기
- 11~12월: 최종발표·수능 반영 → 합격선/경쟁률
- 12~2월: 다음 학년도 시행계획 공개 → 변경사항 페이지 선점
- 3~6월: 원서접수·자격 FAQ·로드맵 (경찰대 접수는 5월, 사관은 6월)
- 7월 말: 1차시험 직후 기출 트래픽 폭증 → 기출 분석 페이지는 미리 준비
